# Design lessons

- 2026-09-13 — Cue group controls must let the accepted artwork carry the hierarchy: use a real image-led capsule with a short label/value stack and selection outline; do not flatten rich assets into centered icons inside empty pills.
- 2026-09-16 — Native Cue selection panels must insert between the configuration controls and action column; never overlay or hide the prompt/actions. Avoid custom stroked glass edges that render jagged; use one clean clipped material owner, collapsed-by-default controls, and explicit icon-only action hierarchy.
- 2026-09-16 — Clear native surfaces still need individually legible control fills; never let buttons, fields, or icon actions collapse into floating text on the desktop background. Use adaptive control-level surfaces and keep the selector row free of an enclosing panel.
- 2026-09-16 — Individually bounded controls must preserve genuine Liquid Glass character without a shared backdrop: native material depth, light response, edge treatment, and translucency are required; a flat semi-transparent fill is not an acceptable substitute.
- 2026-09-16 — A transparent native panel cannot expose the desktop so strongly that it competes with the composer. Provide a restrained blurred/translucent legibility layer, while keeping the product controls individually bounded and avoiding an opaque frame or connected contour.
- 2026-09-16 — Expanded parameter selectors need the full width of the composer block and enough image-led information to support a confident choice; a single tiny slot is insufficient. Their open state is transient: pointer/focus containment keeps it alive, while click-away or Escape dismisses it.
- 2026-09-16 — Treat the prompt text field as the stable visual anchor. Other Cue controls may compact into it when the pointer leaves, then re-emerge together on return with coordinated spring motion; focus must prevent a control from disappearing, and Reduced Motion must remove travel and overshoot.
- 2026-09-16 — Hover-adaptive UI must keep the trigger geometry fixed while its detail panel opens. Use one stable hover-intent state and deterministic choreography; do not let panel measurement feed back into the row being hovered, or the pointer will lose its target and the animation will jitter.
- 2026-09-16 — Group buttons are triggers, not selections. Only an actual Optics/Stage/Finish option can configure the prompt; Edit multi-select indicators belong on chosen options or explicit operation chips, never on an untouched group trigger.
- 2026-09-16 — Selector complexity should follow the domain: Optics can use three named slots, while Stage and Finish need scalable thumbnail/style grids. Do not force every library category into the same generic three-card layout.
