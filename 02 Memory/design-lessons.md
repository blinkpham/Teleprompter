# Design lessons

- 2026-09-13 — Cue group controls must let the accepted artwork carry the hierarchy: use a real image-led capsule with a short label/value stack and selection outline; do not flatten rich assets into centered icons inside empty pills.
- 2026-09-16 — Native Cue selection panels must insert between the configuration controls and action column; never overlay or hide the prompt/actions. Avoid custom stroked glass edges that render jagged; use one clean clipped material owner, collapsed-by-default controls, and explicit icon-only action hierarchy.
- 2026-09-16 — Clear native surfaces still need individually legible control fills; never let buttons, fields, or icon actions collapse into floating text on the desktop background. Use adaptive control-level surfaces and keep the selector row free of an enclosing panel.
